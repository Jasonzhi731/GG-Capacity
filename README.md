# GG-Capacity · 台灣晶圓代工產能版圖

逐廠、逐期盤點台灣四家晶圓代工廠：台積電（TSMC）、聯電（UMC）、世界先進（VIS）、力積電（PSMC），包括海外據點與合資廠。內容涵蓋製程節點、產能、量產時程與產能演進圖表，另有「四家比較」頁。

> **本網站資料由 AI 自動收集、整理與推估，不代表各公司官方實際資料，僅供研究參考，不構成投資建議。**

## 頁面

選單可切換 `#tsmc`、`#umc`、`#vis`、`#psmc`、`#compare`，也可以直接用這些錨點分享特定頁面。

## 檔案

| 檔案 | 用途 |
|---|---|
| `page.html` | 唯一的原始檔。資料集中在 `<script>` 的 DATA 區，每家公司一個區塊（`TSMC`／`UMC`／`VIS`／`PSMC`） |
| `build.py` | 由 `page.html` 產生 `index.html`，加上完整 HTML 骨架與 Google tag |
| `index.html` | GitHub Pages 發布的頁面，由程式產生，請勿手動修改 |

## 資料口徑

- **台積電**：不公布逐廠產能。各期產能為第三方估計，再用 20-F 的官方總量校準。
- **聯電**：每季公布逐廠產能，本站直接採用官方值（年產能 ÷12、季產能 ÷3）。
- **世界先進**：採用官方年產能與季度指引；個別廠多數未公布，拆分值為推估。
- **力積電**：採用官方公司簡報的各廠月產能。

## 更新流程（每週自動執行）

1. 搜尋四家公司的新廠、產能、法說消息，修改 `page.html` 裡對應公司的 DATA 區塊。
2. 執行 `python build.py`。
3. commit 並 push 到 `main`，GitHub Pages 會自動重新部署。
